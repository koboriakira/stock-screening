# CodeTour: 3軸スコアリングの設計と配点

## スコアリングの位置づけ

ソフトフィルタ通過後の銘柄を **数値的に順位付け** するために、
3つのカテゴリ (軸) で独立にスコアリングし、加重合計で総合スコアを算出します。

```
FinancialSnapshot
  ↓
┌───────────────────────────────────────────────┐
│            CompositeScorer.score()             │
│                                               │
│  ValueScorer  ──→ value_raw   ──× 0.40 ──┐   │
│  QualityScorer ─→ quality_raw ──× 0.30 ──┤   │
│  MomentumScorer → momentum_raw ─× 0.30 ──┤   │
│                                     合計 ──┘   │
│                 + ターンアラウンドボーナス (10)   │
│                 → total (上限100)              │
└───────────────────────────────────────────────┘
  ↓
ScoreResult(value, quality, momentum, total)
```

## 加重配分

```python
# shared/config.py
SCORING_WEIGHTS = {
    "value": 0.4,     # 割安性を最重視
    "quality": 0.3,
    "momentum": 0.3,
}
TURNAROUND_BONUS = 10  # 黒字転換ボーナス
```

---

## 軸1: Value (割安スコア) — 0〜100点

投資対象として割安かどうかを4つのサブ指標で評価します。各25点満点。

| サブ指標 | 最低→最高の範囲 | スコア | 考え方 |
|---|---|---|---|
| PER | 30以上→5以下 | 0→25 | PER が低いほど割安 |
| PBR | 2.0以上→0.5以下 | 0→25 | PBR が低いほど割安 |
| ネットキャッシュ比率 | 0%→50%以上 | 5→25 | 現金豊富ほど解散価値が高い |
| 52週高値乖離率 | 0%→30%以上下落 | 0→25 | 高値から大きく下落していると割安候補 |

**スコア算出方法**: 線形補間 (`_linear_interpolate`)

```python
def _linear_interpolate(value, low, high, score_low, score_high):
    # value が low 以下なら score_low、high 以上なら score_high
    # 間は線形にスコアを配分
```

**例**: PER = 10 の場合
- 範囲: 5 (25点) 〜 30 (0点) の間
- スコア = 25 - (10 - 5) / (30 - 5) × 25 = **20.0点**

## 軸2: Quality (質スコア) — 0〜100点

企業の収益力・財務健全性を3つのサブ指標で評価します。

| サブ指標 | 最低→最高の範囲 | スコア | 考え方 |
|---|---|---|---|
| ROE | 0%以下→8%以上 | 0→35 | 資本効率が高い企業を評価 |
| 営業利益率 | 0%以下→10%以上 | 0→35 | 本業の稼ぐ力 |
| 自己資本比率 | 20%未満→50%以上 | 0→30 | 財務の安全性 |

自己資本比率は3段階の区間で補間:
- 20%未満: 0点
- 20%〜30%: 5→15点 (線形)
- 30%〜50%: 15→30点 (線形)
- 50%以上: 30点 (満点)

---

## 軸3: Momentum (変化スコア) — 0〜100点

業績のトレンドや株主還元の変化を3つのサブ指標で評価します。

| サブ指標 | 最低→最高の範囲 | スコア | 考え方 |
|---|---|---|---|
| 売上高成長率 | 0%→20%以上 | 10→35 | 成長トレンド |
| 営業利益成長率 | 0%→30%以上 | 5→35 | 利益拡大の勢い |
| 配当利回り | 0%→4%以上 | 0→30 | 株主還元 (変化のプロキシ) |

**注意**: マイナス成長の場合は0点 (ペナルティなし)。

配当利回りは本来「配当利回りの変化」を測るべきですが、
Phase 1 では前年の配当データが取得困難なため、現在の配当利回りをプロキシとして使用しています。

---

## ターンアラウンドボーナス

前期営業利益が赤字 → 今期黒字転換した銘柄に **+10点** のボーナスを加算します。

```python
# scoring/__init__.py
if prev_operating_profit_negative and snap.operating_profit_growth > 0:
    total += TURNAROUND_BONUS  # +10
total = min(total, 100)  # 上限100でキャップ
```

黒字転換は投資カタリストとして強力なため、特別加点で捕捉します。

---

## None 安全設計

全てのサブ指標は `None` のとき **0点** を返します:

```python
@staticmethod
def score_per(per: float | None) -> float:
    if per is None:
        return 0
    return _linear_interpolate(per, 5.0, 30.0, 25.0, 0.0)
```

これにより、yfinance からデータ取得できなかった銘柄もエラーなくスコアリングされます。
ただし、データ不足銘柄は自然とスコアが低くなり、上位に入りにくくなります。

## ファイル構成

```
discovery/domain/scoring/
├── __init__.py          # CompositeScorer (3軸の統合 + ターンアラウンド)
├── value_score.py       # ValueScorer (PER, PBR, ネットキャッシュ, 52週乖離)
├── quality_score.py     # QualityScorer (ROE, 営業利益率, 自己資本比率)
└── momentum_score.py    # MomentumScorer (売上成長, 営業利益成長, 配当利回り)
```

各 Scorer はステートレスな `@staticmethod` で実装されており、
`FinancialSnapshot` を受け取ってスコアを返すだけの純粋関数です。

## スコア例

| 銘柄 | Value (×0.4) | Quality (×0.3) | Momentum (×0.3) | Total |
|---|---|---|---|---|
| 低PER高ROE銘柄 | 70 (28.0) | 80 (24.0) | 40 (12.0) | **64.0** |
| 成長株 | 30 (12.0) | 50 (15.0) | 90 (27.0) | **54.0** |
| 割安だが低質 | 90 (36.0) | 20 (6.0) | 20 (6.0) | **48.0** |

Value の重みが最大 (40%) のため、同程度の Quality/Momentum なら割安銘柄が上位に来ます。
