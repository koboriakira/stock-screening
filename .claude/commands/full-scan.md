# フルスキャン指示書

あなたはスクリーニングパイプラインの実行アシスタントです。
スクリーニング → 評価 → タイミング判定を一連のパイプラインとして実行し、結果をまとめて報告してください。

## ユーザの指示が必須な要素

なし（デフォルトパラメータで実行可能）

## ユーザからの指示があると望ましい要素

- スクリーニング対象の上位銘柄数（デフォルト: 30）
- テストモードで実行するか（`--test`: 5銘柄のみ）

## あなたのやること

### Step 1: スクリーニング実行

- `uv run stock-screener screen --top {N}` を実行する（デフォルト N=30）
  - ユーザがテストモードを指定した場合は `--test` を付与する
- 出力CSVのパスを記録する（コマンド出力から読み取る）
- エラーが発生した場合は即座にユーザに報告し、継続可否を確認する

### Step 2: 評価実行

- Step 1 の出力CSVを入力として `uv run stock-screener evaluate --input {csv} --output eval_result.csv` を実行する
- エラーが発生した場合は即座にユーザに報告し、継続可否を確認する

### Step 3: タイミング判定

- Step 2 の出力CSVを入力として `uv run stock-screener timing --input eval_result.csv` を実行する
- エラーが発生した場合は即座にユーザに報告し、継続可否を確認する

### Step 4: 結果レポート

各ステップの結果を読み取り、以下をまとめて報告する：

1. **スクリーニング結果サマリー**: 対象銘柄数、フィルタ通過数
2. **評価結果の一覧**: verdict 別に分類して表示
   - INVEST 銘柄: Gate1/Gate2 の判定詳細とともに表示
   - WATCHLIST 銘柄: 一覧表示
   - REJECT 銘柄: 件数のみ表示
3. **INVEST 銘柄のタイミング判定結果**: BUY / WAIT / SKIP を表示
4. **WATCHLIST 銘柄の一覧**: ウォッチリスト追加候補として提案

### Step 5: WATCHLIST 銘柄のウォッチリスト登録（ユーザー承認制）

- WATCHLIST 判定の銘柄がある場合、AskUserQuestion ツールを使ってどの銘柄を追加するか質問する
- ユーザーが選択した銘柄のみ、以下のコマンドで登録する：
  - `uv run stock-screener watchlist-add --ticker {ティッカー} --name {銘柄名}`
- ユーザーが「追加しない」を選んだ場合はスキップする

## 制約

- 各コマンドの実行結果を必ず確認し、エラーが発生した場合は即座に報告すること
- 中間ファイルは screen コマンドのデフォルト出力先を利用すること
- 実行中に市場データ取得エラーが多発する場合、途中経過を報告して継続可否を確認すること
- パイプライン全体の所要時間は銘柄数に依存するため、途中経過を適宜報告すること
